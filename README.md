# general

汎用リポジトリです。

## インストール方法

```bash
git clone https://github.com/hrism/general.git
cd general
```

## 基本的な使い方

1. リポジトリをクローンします
2. 必要なファイルを追加・編集します
3. 変更をコミットしてプッシュします

```bash
# ファイルを追加
git add <ファイル名>

# コミット
git commit -m "変更内容の説明"

# プッシュ
git push origin <ブランチ名>
```

## ファイル構成

```
general/
├── README.md   # プロジェクトの説明（このファイル）
```
